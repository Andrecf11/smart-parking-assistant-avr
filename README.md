# Smart Parking Assistant Prototype (ATmega168)

## 📌 About the Project
An embedded systems academic project developed at ISEP. The goal was to design a hardware and software solution to assist drivers during parking maneuvers by detecting obstacles and providing real-time feedback.

## ⚙️ Features
- Real-time distance measurement using HC-SR04 ultrasonic sensors.
- Progressive audio alerts using a PWM-controlled buzzer (frequency increases as the car gets closer to an obstacle).
- Visual feedback on an I2C 20x4 LCD display.
- LED indicators for distance ranges.
- Custom PCB designed from scratch.

## 🛠️ Technologies Used
- **Language:** C, Assembly
- **Microcontroller:** ATmega168 (AVR)
- **Tools:** Microchip Studio, Visual Studio, KiCad (PCB Design)
- **Hardware:** Ultrasonic Sensors, I2C LCD, Buzzer, LM7805 Voltage Regulator.
